# 提出前チェックリスト

## PDFの構成

- [ ] `main.pdf`が「表紙→埋込み1頁2段アブストラクト→目次→本文→付録（使用時だけ）→生成AI等の利用に関する申告（該当する場合のみ）→謝辞→本文用参考文献→奥付」の順であり，図目次と表目次が出ていない．
- [ ] 表紙，埋込みアブストラクトおよび奥付にページ番号がない．前付にはヘッダ文字と横罫線がなく，本文開始後だけ通常頁に右上ヘッダと横罫線がある．
- [ ] 目次の最終項目がページ下端で欠けたり，本文領域からはみ出したりしていない．
- [ ] 埋込みアブストラクトが目次へ重複掲載されていない．
- [ ] `abstract.pdf`が独立提出用のA4・2段組・ちょうど1頁である．

## 書誌情報

- [ ] `metadata.tex`の年度，和文題目，英文題目，学籍番号，和文氏名，英文氏名，所属，研究室，指導教員，提出日，キーワードをすべて入力した．
- [ ] 表紙，本文，独立アブストラクトで題目，氏名，学籍番号が一致している．
- [ ] 年度，提出日，指導教員，所属および研究室を提出要領の公式表記と照合した．
- [ ] `論文題目を入力`，`English Thesis Title`，`学籍番号`，`氏名`，`Student Name`，`20XX`，`キーワード1`等の初期値が残っていない．
- [ ] 「［架空の記入例・提出不可］」，「情報太郎」，例示用学籍番号，架空の研究内容・数値・図表・研究業績が残っていない．

## 内容

- [ ] 研究目的と結論が対応している．
- [ ] データ分割，比較条件，評価指標，実装条件を記載した．
- [ ] 主要な主張ごとに，対応する比較条件，評価指標，評価単位，結果および限界を示した．
- [ ] データ分割を独立単位で固定し，派生データの混入，評価集合による再調整および評価単位の水増しがない．
- [ ] すべての図，表，番号付き数式を本文から参照し，参照先の番号が正しい．
- [ ] 図中の変数とギリシャ文字は数式用イタリック，単位・演算子・説明的な添字はローマンであり，本文と同じアクセント，上下付きおよび数値表記を用いている．
- [ ] 表題は表の上，図題は図の下にあり，`\label`は対応するキャプションの直後にある．
- [ ] 観測結果，解釈，未検証の推測を区別した．
- [ ] 制限事項，失敗例，適用範囲を記載した．
- [ ] `content/achievements.tex`を確認し，実績がない場合は「該当なし」，ある場合は著者，題目，発表先，発表年，査読と発表状態を正確に記載した．
- [ ] `acknowledgements.tex`を自分の研究に対する謝辞へ書き換え，氏名・所属・役職・研究費等の公式表記と指定文言を確認した．
- [ ] 謝辞に記入例，空欄または説明用コメントが残っていない．

## 生成AI等の利用

- [ ] 提出時点の大学・学部・学科の規則と指導教員の指示を確認した．
- [ ] 生成AI等を利用していない場合，`ai-usage.tex`をコメントだけのままとし，PDFに申告見出しや空白頁が出ていない．
- [ ] 生成AI等を利用した場合，`ai-usage.tex`にサービス名・モデル名・版または利用期間，用途，対象範囲，入力情報，検証した対象と方法，著者の責任を事実に即して記載した．
- [ ] 生成AI等を利用した場合，必要な入力，出力，設定および利用日時等の履歴を，指定された方法で保管した．
- [ ] 個人情報，認証情報，非公開URLまたは未公開研究データを，承認されていない外部AIサービスへ入力していない．
- [ ] 生成AI等がデータ処理，解析，判定，評価または結果生成に関与した場合，方法・実験の章にも条件，検証方法，限界および再現に必要な情報を記載した．
- [ ] AIを著者または根拠資料として扱わず，数値，主張，引用およびコードを原資料，一次文献または実行結果と照合した．
- [ ] 生成AI等の利用申告を`abstract.tex`または`content/abstract.tex`へ追加していない．
- [ ] `examples/ai-usage-example.tex`の架空の利用期間，対象範囲および文章を提出原稿へ残していない．

## 引用と公開範囲

- [ ] 本文の引用キーが`references.bib`に存在する．
- [ ] 未読文献，架空文献，重複文献がない．
- [ ] アブストラクトの参考文献は`\cite{key}`で引用し，`content/abstract.tex`に`\printbibliography`または`\nocite`を記載していない．
- [ ] 埋込みアブストラクトと独立アブストラクトでは，引用がある場合だけ各アブストラクト内に一覧が1回表示されている．
- [ ] 卒業論文本文の参考文献一覧が巻末に1回だけ表示されている．
- [ ] 埋込みアブストラクトと独立アブストラクトで，同じ引用の番号が一致している．
- [ ] 卒業論文本文はアブストラクトと別に採番されることを理解し，番号が異なることを誤りとして手修正していない．
- [ ] 図表，コード，データの利用条件と出典を確認した．
- [ ] `examples/figures/`の合成画像を提出原稿へ残しておらず，利用する全図版の由来と条件を自分の原稿に合わせて確認した．
- [ ] 個人情報，認証情報，非公開URL，機微なデータが残っていない．
- [ ] DICOM，NIfTI，動画，生データ，モデル重み，checkpointおよび実験出力一式をプロジェクトへ含めていない．

- [ ] 最終稿で`Recompile from scratch`を実行し，Biberを含むクリーンな再コンパイルが完了した．
- [ ] ログに`LaTeX Error`，`Package Error`，`undefined citations`，`undefined references`，`Overfull \hbox`または`Overfull \vbox`がない．
- [ ] PDFを検索し，未解決参照を示す`??`や`[?]`がない．
- [ ] IPAex明朝・IPAexゴシックで日本語が正しく表示され，代替フォントや文字化けがない．
- [ ] 文字化け，見切れ，空白ページ，孤立した見出しがない．
- [ ] 表題が表の上，図題が図の下にあり，図表，数式および参考文献の番号を本文から参照できる．
- [ ] 奥付の題目，学籍番号，氏名，所属および提出年月が表紙と一致している．
- [ ] PDFの目視確認後に提出用ファイル名へ変更した．

## Overleafとローカル環境

- [ ] OverleafのCompilerが`LuaLaTeX`，TeX Liveが`2025`，Main documentが目的に応じて`main.tex`または`abstract.tex`になっている．
- [ ] ローカルで作業した場合は，`lualatex`，`biber`，`latexmk`およびIPAexフォントを利用できる環境でクリーンビルドした．
- [ ] Overleafへ戻したファイルはソースと掲載用図だけであり，補助ファイルや生成PDFを混在させていない．

ローカルで物理ページ数を確認する場合は，Popplerに含まれる`pdfinfo`を使えます．`pdfinfo`はmacOSの標準コマンドではありません．利用できない場合は，PDFビューアのページ表示で確認してください．

```bash
pdfinfo abstract.pdf | grep Pages
```
