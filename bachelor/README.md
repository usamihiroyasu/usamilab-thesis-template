# 宇佐美研究室 卒業論文テンプレート

Version 2.0.1，2026-07-29

中部大学 宇佐美研究室で用いる，卒業論文本文と1頁アブストラクトのLuaLaTeXテンプレートです．本配布物は卒業論文用に固定されており，修士論文には別配布の修士論文テンプレートを使います．

本テンプレートは宇佐美研究室の運用資料であり，中部大学，学部または学科の公式様式ではありません．提出時点の指定様式が本テンプレートより優先されます．

## まずここから

初めて使う学生は，次の順に確認してください．

このREADMEは，編集ファイル，PDFの作成方法およびコンパイル手順を説明します．章・段落・図表・実験の組み立ては`WRITING_GUIDE.md`，各`.tex`のコメントはその場所で必要な最小限の記入指示です．

1. この`README.md`で，作るPDF，編集するファイルおよびコンパイル方法を把握する．
2. `WRITING_GUIDE.md`で，章の役割，主張と根拠の対応，図表・数式・引用の書き方を確認する．
3. `examples/README.md`の対応表から，自分が書く通常ファイルと内容入り記入例を対応づける．
4. 提出前に`CHECKLIST.md`を上から実施する．

### ゼロから書かないための開始手順

1. 試行前にOverleafプロジェクトを複製するか，Source ZIPをダウンロードして退避する．
2. `metadata.tex`を入力する．
3. 書く章の通常ファイルと，`examples/`内の対応する内容入り例を，ブラウザの別タブまたは別ウィンドウで並べて確認する．通常ファイルのコメントを必須項目，内容入り例を文章密度とLaTeX記法の見本として使う．
4. 必要なLaTeXの構造だけを通常ファイルへ移し，氏名，研究内容，数値，図表，結果および研究業績を直ちに自分の内容へ置き換える．`examples/`のファイル自体をMain documentに指定したり，通常原稿から`\input`したりしない．
5. `WRITING_GUIDE.md`の推奨順序に従い，提案手法 → 実験・評価 → 問題設定 → 背景・関連研究 → はじめに → おわりにの順で執筆する．アブストラクトは本文の主張と結果が固まってからまとめる．
6. Overleafの全文検索で「架空の記入例」「情報太郎」「20XX」「XX」を検索する．`examples/`，README，WRITING_GUIDE，CHECKLIST，CHANGELOG，LICENSE，NOTICEおよびクラス／スタイル内の定義にある説明用の一致は対象外とする．`metadata.tex`，`content/`，`chapters/`，`ai-usage.tex`，`acknowledgements.tex`，`appendix.tex`および生成PDFに例示内容が残っていないことを確認してから`CHECKLIST.md`へ進む．

内容入り例は空白からの開始を避けるための足場です．研究固有の事実，論理，結果および文章は，学生本人が実際の研究に基づいて記載してください．

## 完成するPDF

`main.tex`から作る卒業論文本文は，次の順序へ固定されています．

1. 表紙
2. 表紙直後へ埋め込むA4・1頁・2段組アブストラクト
3. 目次
4. 卒業論文本文
5. 付録（使用する場合だけ）
6. 生成AI等の利用に関する申告（該当する場合のみ）
7. 謝辞
8. 卒業論文本文の参考文献
9. 奥付

埋込みアブストラクトは目次へ載せず，ページ番号も表示しません．生成AI等を利用していない場合，`ai-usage.tex`はコメントだけのままとし，申告見出しも空白頁も出力しません．申告は卒業論文本文だけに含まれ，独立アブストラクトには含まれません．卒業論文では図目次と表目次を出力しない構成へ固定しています．同じアブストラクト内容を`abstract.tex`から独立提出用の1頁PDFとしても作れます．表紙，埋込みアブストラクト，目次，図目次，表目次，参考文献または奥付を手作業で`main.tex`へ追加しないでください．

## 最初に1回だけ行う設定

1. Overleafで`New Project` → `Upload Project`を選び，このZIPをアップロードする．
2. `Settings`（左下の歯車）→ `Compiler`を開き，Compilerを`LuaLaTeX`，TeX Liveをローカル検証環境と同じ`2025`にする．同じ画面のMain documentで，作るPDFに応じて`main.tex`または`abstract.tex`を選ぶ．
3. `metadata.tex`の全項目を提出要領と照合して入力する．対象は，年度，和文題目，英文題目，学籍番号，和文氏名，英文氏名，所属，研究室，指導教員，提出日，キーワードである．図目次と表目次の設定はなく，卒業論文では両方とも固定OFFである．
4. `main.tex`は原則として編集しない．章数または章順を変更する場合だけ，指導教員と合意したうえで，章を読み込む`\input{chapters/...}`の並びを変更する．前付，`refsection`，付録，後付および参考文献出力は変更しない．`abstract.tex`，`usamilab-*.sty`，`usamilab-thesis.cls`および`usamilab-profile.tex`も，特別な指示がない限り編集しない．

## 卒業論文本文を作る

1. `Settings`（左下の歯車）→ `Compiler`→ Main documentで`main.tex`を選ぶ．
2. `content/abstract.tex`，`content/achievements.tex`，`chapters/`以下，`acknowledgements.tex`，必要に応じて`ai-usage.tex`と`appendix.tex`を編集する．
3. `references.bib`へ実際に読んだ文献を登録し，本文中で`\cite{key}`を使う．
4. Recompileする．OverleafではBibLaTeX用のBiberも自動実行される．引用番号が更新されない場合は，Recompileメニューから`Recompile from scratch`を実行する．
5. 生成PDFを開き，表紙，埋込み1頁アブストラクト，目次，各章，使用する場合の付録，該当する場合の生成AI等の利用申告，謝辞，本文用参考文献，奥付の順序と表示を確認する．図目次と表目次が出ていないことも確認してダウンロードし，直後に本文だと分かる作業用ファイル名へ変更する．

## 1頁アブストラクトだけを作る

1. `metadata.tex`，`content/abstract.tex`，`content/achievements.tex`および`references.bib`を編集する．研究業績がない場合は「該当なし」とし，投稿予定は記載しない．
2. `Settings`（左下の歯車）→ `Compiler`→ Main documentで`abstract.tex`へ切り替える．
3. Recompileする．`content/abstract.tex`で引用した文献がある場合だけ，参考文献見出しと一覧が末尾に自動で1回出力される．手動で見出しや`\printbibliography`を追加しない．
4. 生成PDFを開き，A4・2段組・ちょうど1頁であることを確認してダウンロードする．ダウンロード直後に，アブストラクトだと分かる別の作業用ファイル名へ変更する．2頁以上になると`usamilab-abstract`がエラーを出す．本文，図表および参考文献を簡潔に調整し，余白，文字サイズまたはスタイルファイルで無理に収めない．
5. 卒業論文本文の編集へ戻る場合は，Main documentを`main.tex`へ戻す．

生成AI等の利用申告は卒業論文本文の後付であり，1頁アブストラクトには含めません．`abstract.tex`へ`ai-usage.tex`を追加しないでください．

OverleafではMain documentを一度に1つだけ指定します．また，ダウンロードしたPDFの既定名は通常，Main document名ではなくOverleafのプロジェクト名です．本文をダウンロードした直後に，たとえば`学籍番号_氏名_卒業論文本体.pdf`へ変更し，次にアブストラクトをダウンロードして`学籍番号_氏名_卒業論文アブスト.pdf`のような別名へ変更してください．最終提出時は，必ず当年度の提出要領が指定するファイル名へ揃えます．

## 学生が編集するファイル

| ファイル | 内容 |
|---|---|
| `metadata.tex` | 題目，氏名，学籍番号，所属，年度，指導教員，キーワード |
| `content/abstract.tex` | 本文へ埋め込む版と独立版で共用するアブストラクト本文 |
| `content/achievements.tex` | 埋込み版と独立版で共用する研究業績欄 |
| `chapters/*.tex` | 卒業論文本文 |
| `ai-usage.tex` | 該当する場合だけ記載する生成AI等の利用申告 |
| `acknowledgements.tex` | 学生本人の研究に対する謝辞 |
| `appendix.tex` | 必要な場合だけ使う付録 |
| `references.bib` | 参考文献データベース |
| `figures/` | 図ファイルと取扱い上の注意 |

`examples/`は架空の内容入り記入例です．通常のビルドには読み込まれません．対応関係と安全な使い方は`examples/README.md`を参照してください．

## 目次とヘッダ

卒業論文の前付は目次だけであり，図目次と表目次は固定OFFです．表紙，埋込みアブストラクトおよび前付ではヘッダ文字と横罫線を表示しません．本文開始後にだけ`fancy`ページスタイルへ切り替え，通常頁へ右上ヘッダ，横罫線および右下ページ番号を表示します．章扉等の`plain`頁にはヘッダ罫線を表示しません．

目次では，項目が多い場合でも最終項目がページ下端で欠けないよう，目次だけ行間と章項目間隔を調整しています．このためにクラスファイルの余白や行間を変更しないでください．

## 学部用の推奨構成

本文は「はじめに／背景・関連研究／問題設定／提案手法／実験・評価／おわりに」を初期構成とします．章名，章数または章順は研究内容に応じて変更できますが，指導教員と合意し，`main.tex`では章を読み込む`\input{chapters/...}`の並びだけを変更してください．アブストラクトも初期構成では「はじめに／おわりに」を用います．

各章ファイルには，何を書くか，何を区別するか，対応する内容入り例をコメントで記載しています．章全体の書き方は`WRITING_GUIDE.md`，提出前の完了条件は`CHECKLIST.md`で確認してください．内容入りの例は`examples/`へ隔離し，可視注記を「［架空の記入例・提出不可］」へ統一しています．通常の原稿には読み込まれません．

## 参考文献

BibLaTeXとBiberへ統一しています．`content/abstract.tex`には文章，図表，数式および`\cite{key}`だけを書き，`\nocite`や`\printbibliography`は置きません．一覧の出力は各ドライバが管理します．DOIとURLは照合用に`references.bib`へ保持しますが，提出版の書式に合わせて参考文献一覧へは表示しません．

引用番号の範囲は次のように分離されています．

- `main.pdf`内の埋込みアブストラクト
- `main.pdf`内の卒業論文本文
- `abstract.pdf`の独立アブストラクト

埋込み版と独立版は同じ`content/abstract.tex`を`sorting=none`で処理するため，内容を同じに保てばアブストラクト内の引用番号も一致します．卒業論文本文は別の`refsection`で採番するため，本文巻末の番号がアブストラクトと異なっても正常です．同じ文献をアブストラクトと本文の両方で引用した場合，アブストラクト内と本文巻末の各一覧へ現れることも意図した動作です．各範囲内で一覧が1回だけ出力されていることを確認してください．

## 生成AI等の利用に関する申告

生成AI等を利用していない場合，`ai-usage.tex`はコメントだけのままにします．利用した場合だけ，`examples/ai-usage-example.tex`の構成を参考に，番号なしの「生成AI等の利用に関する申告」を作成します．申告は`main.tex`から謝辞の直前にだけ読み込まれ，独立アブストラクトのページ数には影響しません．

申告には，実際に利用したサービス名・モデル名・版または利用期間，用途と対象範囲，入力した情報の範囲，出力を人間が検証した対象と方法，最終内容に対する著者の責任を記載します．AIを著者や根拠資料の代わりにせず，数値，主張，引用およびコードを原資料，一次文献または実行結果と照合してください．入力内容や利用履歴の保存を求められた場合は，指定された方法で保管します．

生成AI等がデータ処理，解析，判定，評価または結果生成に関与した場合，後付の申告だけでは再現性を満たしません．使用条件，プロンプト等の条件，出力の検証方法，誤りへの対処および限界を，方法・実験の章にも記載します．提出時点の大学・学部・学科の規則と指導教員の指示が，本テンプレートの記載例より優先されます．

運用確認には，[中部大学「生成AI利用ガイドライン（第2報）」](https://www.chubu.ac.jp/news/24270/)，[IEEE Author Guidelines for Artificial Intelligence Generated Text](https://open.ieee.org/author-guidelines-for-artificial-intelligence-ai-generated-text/)および申告形式の参考例である[Usamiらの論文](https://arxiv.org/abs/2606.15610)も参照してください．これらの案内を，当年度の提出要領または指導教員の指示に代えることはできません．

## Overleafでの運用

- 卒業論文と修士論文は別プロジェクトとしてアップロードする．
- Compilerは`LuaLaTeX`，TeX Liveは`2025`とし，独自にpdfLaTeXやXeLaTeXへ変更しない．
- Main documentは`Settings`（左下の歯車）→ `Compiler`で切り替える．本文を作るときは`main.tex`，独立アブストラクトを作るときは`abstract.tex`を選ぶ．
- 引用，目次または相互参照が更新されないときは`Recompile from scratch`を実行する．
- 本文PDFとアブストラクトPDFは，ダウンロード直後に識別できる別名へ変更し，それぞれのページ構成をPDFビューアで確認する．

Main documentの設定は，Overleaf公式の[The Main document](https://docs.overleaf.com/getting-started/recompiling-your-project/the-main-document)も参照してください．

## ローカルでのビルド

TeX Live 2025以降を想定しています．macOSではフル構成のMacTeXまたはTeX Liveを推奨します．LuaLaTeX，Biber，latexmkおよびIPAexフォントを利用できることを，次のように確認します．

```bash
lualatex --version
biber --version
latexmk -v
```

プロジェクトのルートで次を実行します．

```bash
latexmk main.tex
latexmk abstract.tex
```

`latexmk`がLuaLaTeXとBiberの必要な再実行を管理します．生成物を削除する場合は`latexmk -C`を使い，その後もう一度上記2本をビルドします．

### Overleafで大容量・長時間ビルドになる場合

高解像度画像や多数の図によってアップロードまたはコンパイルが重くなった場合は，Source ZIPを取得し，ローカルでビルドしてください．DICOM，NIfTI，動画，生データ，モデル重み，checkpointおよび実験出力一式はLaTeXの入力ではないため，Overleafへ置きません．承認された研究用ストレージで管理し，論文には掲載に必要な最終図だけを`figures/`へ出力します．

折れ線図，模式図および文字を含む図は可能ならPDF，写真や画像例は用途に応じてPNGまたはJPEGを使います．巨大な元画像を`\includegraphics`の表示倍率だけで縮小せず，掲載寸法に見合う解像度の派生画像を書き出してください．

Overleafへ戻すときは，更新した`.tex`，`.bib`，クラス・スタイルファイルおよび掲載用図だけを同期します．`.aux`，`.bbl`，`.bcf`，`.blg`，`.fdb_latexmk`，`.fls`，`.log`，`.out`，`.run.xml`，`.toc`，`main.pdf`および`abstract.pdf`は再生成物なのでアップロードしません．ローカルとOverleafの結果を比較する場合は，CompilerとTeX Liveの世代を揃えます．

## コンパイルで困った場合

- 未記入の初期状態では，metadata未設定と`Empty bibliography`の警告が出る．入力後の最終稿では，metadataを埋め，引用がある場合は参考文献一覧が生成されて警告が解消したことを確認する．
- 本版は`luatexja-preset`の`ipaex`設定を使う．IPAexフォントが見つからない場合は，TeX Liveの不足パッケージを追加するか，フル構成のMacTeX／TeX Liveへ切り替える．クラスファイルを別フォントへ書き換えて回避しない．
- 引用が`[?]`，相互参照が`??`のままなら，Overleafで`Recompile from scratch`を実行する．
- それでも直らない場合は，引用キーと`references.bib`の登録，`\label`と`\ref`の綴りを照合する．
- `Overfull \hbox`または`Overfull \vbox`が出た場合は，長いURL，数式，表，図または文章を調整する．見切れがないかPDFも目視する．
- ページ数エラー後にもPDFが生成される場合があるため，エラー表示だけでなくPDFの物理ページ数を確認する．

## 提出前

`CHECKLIST.md`を上から確認してください．とくに，全metadata，架空例の残存，研究業績，生成AI等の利用申告，各引用範囲の参考文献一覧，埋込み版と独立版の引用番号，未解決参照，匿名化およびアブストラクト1頁を確認します．

## テンプレートへの謝意と由来

本テンプレートを再構成するにあたり，卒業論文テンプレートをご提供いただいた奥居先生に感謝申し上げます．

提供された旧テンプレート内部には，石原進先生作成のクラスファイルを基にした旨の記載がありました．先行する組版整備に敬意を表します．この来歴は旧ファイル内の記載に基づくものであり，原資料，改変履歴および権利関係を独立に確認したものではありません．両先生の氏名の記載は，本テンプレートの監修，承認または内容保証を意味しません．

本テンプレートのLaTeXコードは，宇佐美研究室がLuaLaTeX向けに新たに再構成したものです．旧テンプレートに含まれていたクラスファイル，スタイルファイル，フォント設定ファイル等は，同梱・再配布していません．詳細は`NOTICE.md`を参照してください．
