## 機能検証

- 卒業論文では図目次と表目次を出力せず，修士論文では両者を個別にON／OFFできる．
- 論文本体とアブストラクトは別`refsection`で採番し，一方への引用追加が他方の番号へ影響しない．
- 生成AI等の利用申告は，`ai-usage.tex`に本文がある場合だけ謝辞の直前へ出力する．未使用時は見出し，目次項目または空白ページを生成しない．
- 卒業論文の埋込みアブストと単独アブストは同じ本文入力と描画処理を共有する．
- 表題は表の上，図題は図の下に配置し，本文中の図，表，式および参考文献の相互参照を確認した．
- 表紙と前付ではヘッダ文字と横罫線を出さず，本文開始後だけ所定のヘッダを出力する．
- 内容入り記入例の図中数式は本文の数式規約と整合し，図境界からのはみ出しがない．
- ルートREADMEから学位別README，執筆ガイド，内容入り例および提出前チェックへ直接移動できる．
- README，執筆ガイドおよびTeXコメントの責務を分離し，章構成，主張と根拠，実験妥当性およびアブストラクト構成を学生向けに案内している．
- 完成順序へ任意の付録を含め，章構成変更時の`main.tex`編集範囲を章の`\input`行へ限定した．
- 修士2頁アブストラクトの表2点は，本文中の初回参照より後へ配置している．

## ZIP再展開

正式Source ZIP 2点を空の一時ディレクトリへ再展開し，`main.tex`と`abstract.tex`をクリーンビルドした．ページ数と検査結果は正式ソースと一致した．ZIP integrity testも2点とも合格した．ZIPには本文／アブストの生成PDF，補助ファイル，ログ，キャッシュ，提出者の個人情報，非公開研究データまたは大容量データを含めていない．`examples/figures/`のPDFは，LaTeXから参照する掲載用図版である．

## 完全性

ルートの`SHA256SUMS`には，GitHub Releaseで配布するSource ZIP 2点と，記入例PDF 4点のSHA-256を記録している．配布時は次で照合できる．

```bash
shasum -a 256 -c SHA256SUMS
```

Source ZIPはGitHub Releaseの添付資産であり，リポジトリ本体には重複して収録しない．
