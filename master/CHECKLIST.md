# 提出前チェックリスト

## PDFの構成

- [ ] `main.pdf`が「表紙→目次→設定した図目次／表目次→本文→付録（使用時だけ）→生成AI等の利用申告（利用時だけ）→謝辞→本文用参考文献→奥付」の順である．
- [ ] 修士論文本文へアブストラクトが組み込まれていない．
- [ ] `metadata.tex`の`\UsamiShowListOfFigures`と`\UsamiShowListOfTables`が，それぞれ提出要領に沿う`true`または`false`になっている．
- [ ] 表紙と奥付にページ番号がなく，前付のローマ数字と本文の算用数字が正しい．前付にはヘッダ文字と横罫線がなく，本文開始後だけ通常頁に右上ヘッダと横罫線がある．
- [ ] 目次の最終項目がページ下端で欠けたり，本文領域からはみ出したりしていない．
- [ ] `abstract.pdf`が独立提出用のA4・2段組・ちょうど2頁である．

## 書誌情報

- [ ] 表紙，本文，アブストラクトで題目，氏名，学籍番号が一致している．
- [ ] 年度，和文題目，英文題目，学籍番号，和文氏名，英文氏名を確認した．
- [ ] 所属，研究室，指導教員，提出日，キーワードを公式表記と照合した．
- [ ] `論文題目を入力`，`English Thesis Title`，`学籍番号`，`氏名`，`Student Name`，`所属の正式名称`，`20XX`，`キーワード1`等の初期値が残っていない．
- [ ] 「情報太郎」，「［架空の記入例・提出不可］」，架空の症例数・結果等を含む記入例が残っていない．

## 内容

- [ ] 研究目的と結論が対応している．
- [ ] データ分割，比較条件，評価指標，実装条件を記載した．
- [ ] 主要な主張ごとに，対応する比較条件，評価指標，評価単位，結果および限界を示した．
- [ ] データ分割を独立単位で固定し，派生データの混入，評価集合による再調整および評価単位の水増しがない．
- [ ] すべての図，表，番号付き数式を本文から参照し，参照先の番号が正しい．
- [ ] 図中の変数とギリシャ文字は数式用イタリック，単位・演算子・説明的な添字はローマンであり，本文と同じアクセント，上下付きおよび数値表記を用いている．
- [ ] 表題は表の上，図題は図の下にあり，`\label`は対応するキャプションの直後にある．
- [ ] 観測結果，解釈，未検証の推測を区別した．
- [ ] 制限事項，失敗例，適用範囲を記載した．
- [ ] `acknowledgements.tex`を自分の研究に対する謝辞へ書き換え，氏名・所属・役職・研究費等の公式表記と指定文言を確認した．
- [ ] 謝辞に記入例，空欄または説明用コメントが残っていない．

## 生成AI等の利用

- [ ] 提出時点の大学・研究科・専攻の規則と指導教員の指示を確認し，本テンプレートより優先した．
- [ ] 生成AI等を利用していない場合は，`ai-usage.tex`をコメントだけのままとし，申告見出しや空白頁が出力されていない．
- [ ] 生成AI等を利用した場合は，`ai-usage.tex`にサービス名，モデル名，版，利用期間，用途，入力情報の範囲，出力の検証対象・方法および著者の最終責任を事実に即して記載した．
- [ ] 生成AI等を利用した場合だけ，利用申告が修士論文本体の謝辞前にあり，独立2頁アブストラクトへは組み込まれていない．
- [ ] 生成AI等がデータ生成，前処理，解析，推論，評価者または判定器等として研究方法に関与した場合は，方法・実験章にもモデル，版，入出力，設定，検証方法および限界を記載した．
- [ ] AIの出力に含まれる引用，数値，コード，図表および主張を，原資料，一次文献，実行ログまたは再実行により確認した．
- [ ] プロンプト，出力，利用日時および検証過程を，提出後にも説明できる形で保管した．
- [ ] DICOM，NIfTI，患者情報，症例対応表，個人情報，非公開URL，認証情報および未公開研究データを，承認されていない外部サービスへ入力していない．

## 引用と公開範囲

- [ ] 本文の引用キーが`references.bib`に存在する．
- [ ] 未読文献，架空文献，重複文献がない．
- [ ] 図表，コード，データの利用条件と出典を確認した．
- [ ] `examples/figures/`のCC0腹部CT画像と架空の重畳結果を提出原稿へ残しておらず，利用する全図版の由来と条件を自分の原稿に合わせて確認した．
- [ ] 個人情報，認証情報，非公開URL，機微なデータが残っていない．
- [ ] `content/achievements.tex`の著者，題目，会議名，開催年，査読・発表状況が正確である．
- [ ] 実績がない場合は「該当なし」とし，投稿予定を研究業績へ含めていない．

## 参考文献

- [ ] アブストラクトの参考文献は`\cite{key}`で引用し，`\nocite`と`\printbibliography`を書いていない．
- [ ] 修士論文本文にも`\cite`だけを使い，手入力の引用番号や`\printbibliography`を章へ追加していない．
- [ ] 引用がある場合，独立アブストラクトの参考文献一覧が1回だけ表示され，重複していない．
- [ ] 引用がある場合，修士論文本文の参考文献一覧が巻末に1回だけ表示されている．
- [ ] 修士論文本文と独立アブストラクトは別に採番され，番号が異なることを誤りとして手修正していない．
- [ ] 引用がある場合，Biber実行後のログにundefined citation，empty bibliography等の警告がない．

## PDF

- [ ] LuaLaTeXで`main.tex`と`abstract.tex`がエラーなくビルドできる．
- [ ] IPAex明朝・IPAexゴシックで日本語が正しく表示され，代替フォントや文字化けがない．
- [ ] 文字化け，見切れ，空白ページ，孤立した見出しがない．
- [ ] ログにundefined references，`??`，Overfull，PackageErrorがない．
- [ ] Overleafで`Recompile from scratch`を実行した後も同じ結果になる．
- [ ] 表題が表の上，図題が図の下にあり，図表，数式および参考文献の番号を本文から参照できる．
- [ ] 奥付の題目，学籍番号，氏名，所属および提出年月が表紙と一致している．
- [ ] PDFの目視確認後に提出用ファイル名へ変更した．

## データとビルド環境

- [ ] DICOM，NIfTI，動画，生データ，モデル重み，checkpointおよび実験出力一式をプロジェクトへ含めていない．
- [ ] OverleafのCompilerが`LuaLaTeX`，TeX Liveが`2025`，Main documentが目的に応じて`main.tex`または`abstract.tex`になっている．
- [ ] ローカルで作業した場合は，`lualatex`，`biber`，`latexmk`およびIPAexフォントを利用できる環境でクリーンビルドした．
- [ ] Overleafへ戻したファイルはソースと掲載用図だけであり，補助ファイルや生成PDFを混在させていない．

ローカルで物理ページ数を確認する場合は，Popplerに含まれる`pdfinfo`を使います．macOSでコマンドがない場合は，Homebrew等でPopplerを導入してから次を実行します．

```bash
pdfinfo abstract.pdf | grep Pages
```
