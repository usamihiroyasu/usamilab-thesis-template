# 宇佐美研究室 修士論文テンプレート

Version 2.0.1，2026-07-29

中部大学 宇佐美研究室で用いる，修士論文本文と2頁アブストラクトのLuaLaTeXテンプレートです．本配布物は修士論文用に固定されており，卒業論文には別配布の卒業論文テンプレートを使います．

本テンプレートは宇佐美研究室の運用資料であり，中部大学，研究科または専攻の公式様式ではありません．提出時点の指定様式が本テンプレートより優先されます．

## まずここから

初めて使う学生は，次の順に確認してください．

このREADMEは，編集ファイル，PDFの作成方法およびコンパイル手順を説明します．章・段落・図表・実験の組み立ては`WRITING_GUIDE.md`，各`.tex`のコメントはその場所で必要な最小限の記入指示です．

1. この`README.md`で，作るPDF，編集するファイルおよびコンパイル方法を把握する．
2. `WRITING_GUIDE.md`で，章の役割，主張と根拠の対応，図表・数式・引用の書き方を確認する．
3. `examples/README.md`の対応表から，自分が書く通常ファイルと内容入り記入例を対応づける．
4. 提出前に`CHECKLIST.md`を上から実施する．

### ゼロから書かないための開始手順

1. 試行前にOverleafプロジェクトを複製するか，Source ZIPをダウンロードして退避する．
2. `metadata.tex`を入力する．
3. 書く章の通常ファイルと，`examples/`内の対応する内容入り例を，ブラウザの別タブまたは別ウィンドウで並べて確認する．通常ファイルのコメントを必須項目，内容入り例を文章密度とLaTeX記法の見本として使う．
4. 必要なLaTeXの構造だけを通常ファイルへ移し，氏名，研究内容，数値，図表，結果および研究業績を直ちに自分の内容へ置き換える．`examples/`のファイル自体をMain documentに指定したり，通常原稿から`\input`したりしない．
5. `WRITING_GUIDE.md`の推奨順序に従い，提案手法 → 実験・評価 → 問題設定 → 背景・関連研究 → 緒言 → 結言の順で執筆する．アブストラクトは本文の主張と結果が固まってからまとめる．
6. Overleafの全文検索で「架空の記入例」「情報太郎」「20XX」「XX」を検索する．`examples/`，README，WRITING_GUIDE，CHECKLIST，CHANGELOG，LICENSE，NOTICEおよびクラス／スタイル内の定義にある説明用の一致は対象外とする．`metadata.tex`，`content/`，`chapters/`，`ai-usage.tex`，`acknowledgements.tex`，`appendix.tex`および生成PDFに例示内容が残っていないことを確認してから`CHECKLIST.md`へ進む．

内容入り例は空白からの開始を避けるための足場です．研究固有の事実，論理，結果および文章は，学生本人が実際の研究に基づいて記載してください．

## 完成するPDF

`main.tex`から作る修士論文本文は，次の順序です．

1. 表紙
2. 目次
3. 図目次（`metadata.tex`でONにした場合）
4. 表目次（`metadata.tex`でONにした場合）
5. 修士論文本文
6. 付録（使用する場合だけ）
7. 生成AI等の利用に関する申告（利用した場合だけ）
8. 謝辞
9. 修士論文本文の参考文献
10. 奥付

生成AI等を利用していない場合は，`ai-usage.tex`をコメントだけのままにします．このとき見出しも空白頁も出力されません．利用した場合だけ，事実に即した番号なし章を修士論文本体の謝辞前へ出力します．この申告は独立2頁アブストラクトへ組み込みません．修士論文本文へアブストラクトは組み込まず，アブストラクトは`abstract.tex`からA4・2段組・ちょうど2頁の独立PDFとして作成します．図目次と表目次は`metadata.tex`から個別にON／OFFし，手作業で`main.tex`へ追加・削除しません．表紙，目次，参考文献または奥付も手作業で追加しないでください．

## 最初の設定

1. Overleafで`New Project` → `Upload Project`を選び，このZIPをアップロードする．
2. `Settings`（左下の歯車）→ `Compiler`を開き，Compilerを`LuaLaTeX`，TeX Liveをローカル検証環境と同じ`2025`にする．同じ画面のMain documentで，作るPDFに応じて`main.tex`または`abstract.tex`を選ぶ．
3. `metadata.tex`の全項目を提出要領の正式表記で入力し，図目次と表目次をそれぞれ`true`または`false`に設定する．

`metadata.tex`には，年度，和文題目，英文題目，学籍番号，和文氏名，英文氏名，所属，研究室，指導教員，提出日，キーワード，図目次設定および表目次設定があります．表紙，本文，アブストラクトへ同じ書誌情報が反映されるため，別ファイルへ題目や氏名を重複入力する必要はありません．

## 修士論文本文を作る

1. `Settings`（左下の歯車）→ `Compiler`→ Main documentで`main.tex`を選ぶ．
2. `chapters/`以下，`acknowledgements.tex`，必要なら`appendix.tex`を編集する．生成AI等を利用した場合だけ，`ai-usage.tex`も編集する．
3. 文献を`references.bib`へ登録し，本文中で`\cite{key}`を使う．
4. Recompileして生成PDFを開き，表紙，目次，設定した図目次／表目次，各章，使用する場合の付録，利用時だけ生成AI等の利用申告，謝辞，参考文献，奥付の順序を目視確認してダウンロードする．ダウンロード直後に，本文だと分かる作業用ファイル名へ変更する．

初期構成は「緒言／背景・関連研究／問題設定／提案手法／実験・評価／結言」です．章名，章数または章順は研究内容に応じて変更できますが，指導教員と合意し，`main.tex`では章を読み込む`\input{chapters/...}`の並びだけを変更してください．本文の参考文献一覧は`main.tex`が巻末へ1回だけ出力します．

## 2頁アブストラクトだけを作る

1. `metadata.tex`，`content/abstract.tex`，`content/achievements.tex`および`references.bib`を編集する．
2. `Settings`（左下の歯車）→ `Compiler`→ Main documentで`abstract.tex`へ切り替える．
3. 文献は`references.bib`から`\cite{key}`で引用し，研究業績は`content/achievements.tex`へ記載する．実績がない場合は「該当なし」とし，投稿予定は含めない．
4. Recompileして生成PDFを開き，A4・2段組・ちょうど2頁であることを確認してダウンロードする．ダウンロード直後に，アブストラクトだと分かる別の作業用ファイル名へ変更する．
5. 引き続き修士論文を編集するときは，Main documentを`main.tex`へ戻す．

OverleafではMain documentを一度に1つだけ指定します．また，ダウンロードしたPDFの既定名は通常，Main document名ではなくOverleafのプロジェクト名です．本文をダウンロードした直後に，たとえば`学籍番号_氏名_修士論文本体.pdf`へ変更し，次にアブストラクトをダウンロードして`学籍番号_氏名_修士論文アブスト.pdf`のような別名へ変更してください．最終提出時は，必ず当年度の提出要領が指定するファイル名へ揃えます．

`content/abstract.tex`内の`\AbstractPageBreak`が1頁目と2頁目の境界です．この命令を削除しないでください．内容の区切りに応じて位置を調整できますが，調整後は両頁の密度と読み順を確認してください．1頁または3頁以上では`usamilab-abstract`がエラーを出します．ページ数が合わない場合は，冗長な文章を削り，図表を可読性の範囲で整理し，意図しない空行や空白を確認します．クラス，フォントサイズ，行間，余白を変更して2頁へ押し込まないでください．調整後はOverleafのRecompileメニューから`Recompile from scratch`を実行し，PDFを再確認します．

独立アブストラクトの参考文献一覧は`abstract.tex`が自動的に1回だけ出力します．引用がなければ「参考文献」の見出しも出ません．`content/abstract.tex`へ`\printbibliography`を書いたり，`abstract.tex`を編集したりする必要はありません．

生成AI等の利用申告は修士論文本体の後付であり，独立2頁アブストラクトのページ数へ含めません．アブストラクトだけを作る場合も`ai-usage.tex`は読み込まれません．

## 学生が編集するファイル

| ファイル | 内容 |
|---|---|
| `metadata.tex` | 年度，日英題目，日英氏名，学籍番号，所属，研究室，指導教員，提出日，キーワード，図目次／表目次の切替 |
| `content/abstract.tex` | 独立提出用2頁アブストラクトの本文 |
| `content/achievements.tex` | 独立アブストラクトの研究業績欄 |
| `chapters/*.tex` | 修士論文本文 |
| `ai-usage.tex` | 生成AI等を利用した場合だけ記載する申告．未使用時はコメントだけにする |
| `acknowledgements.tex` | 学生本人の研究に対する謝辞 |
| `appendix.tex` | 必要な場合だけ使う付録 |
| `references.bib` | 参考文献データベース |
| `figures/` | 図ファイルと取扱い上の注意 |

`main.tex`は原則として編集しません．章数または章順を変更する場合だけ，指導教員と合意したうえで，章を読み込む`\input{chapters/...}`の並びを変更します．前付，`refsection`，付録，後付および参考文献出力は変更しません．`abstract.tex`，`usamilab-*.sty`，`usamilab-thesis.cls`および`usamilab-profile.tex`も，特別な指示がない限り編集しません．

## 図目次・表目次とヘッダ

修士論文本体では，`metadata.tex`の次の2行を個別に設定します．初期値は両方とも`true`です．

```tex
\UsamiShowListOfFigures{true} % 図目次を出力する．不要ならfalse
\UsamiShowListOfTables{true}  % 表目次を出力する．不要ならfalse
```

指定できる値は小文字の`true`または`false`だけです．図目次だけ，表目次だけ，両方，どちらも出力しない，の4通りを選べます．当年度の提出要領と指導教員の指示を優先してください．

表紙と前付ではヘッダ文字と横罫線を表示しません．本文開始後にだけ`fancy`ページスタイルへ切り替え，通常頁へ右上ヘッダ，横罫線および右下ページ番号を表示します．章扉等の`plain`頁にはヘッダ罫線を表示しません．目次では，最終項目がページ下端で欠けないよう，目次だけ行間と章項目間隔を調整しています．

## 本文とアブストラクトの引用分離

修士論文本文と独立アブストラクトは別文書であり，引用番号体系も分離されています．`main.tex`は`content/abstract.tex`を読み込みません．修士論文本文は各章での引用順，独立アブストラクトはアブストラクト内の引用順に，それぞれ`sorting=none`で採番します．同じ文献でも両PDFの番号が異なる場合があり，それが正常です．番号を一致させるために引用順を変えたり，番号を直接入力したりしないでください．

文献処理はBibLaTeXとBiberへ統一しています．`content/abstract.tex`と各章には文章，図表，数式および`\cite{key}`だけを書き，`\nocite`と`\printbibliography`は書きません．本文の一覧は`main.tex`，独立アブストラクトの一覧は`abstract.tex`が各PDFへ1回だけ出力します．DOIとURLは照合用に`references.bib`へ保持しますが，提出版の書式に合わせて参考文献一覧へは表示しません．OverleafはRecompile時にBiberも実行します．引用を追加・削除した後に番号や一覧が更新されない場合は，`Recompile from scratch`を実行してください．研究業績は文献引用ではなく，`content/achievements.tex`へ著者，題目，会議名，開催年，査読・発表状況を直接記載します．

## 生成AI等の利用申告

生成AI等を利用した場合は，提出時点の大学・研究科・専攻の規則と指導教員の指示を先に確認し，それらを本テンプレートより優先してください．`ai-usage.tex`には，サービス名，モデル名，版，利用期間，用途，入力した情報の範囲，出力の検証方法および人間が最終責任を負う旨を，実際の利用記録に基づいて記載します．プロンプト，出力，利用日時および検証過程は，提出後にも説明できる形で保管してください．生成AI等を利用していない場合は，雛形をコメント解除せず，ファイルをコメントだけのままにします．

生成AI等が文章作成や実装補助ではなく，データ生成，前処理，解析，推論，評価者または判定器等として研究方法に関与した場合は，`ai-usage.tex`だけでは不十分です．方法・実験章にもモデル，版，入力，出力，設定，検証方法および限界を再現可能な範囲で記載します．AIの出力は文献や実験結果の代わりにならず，引用，数値，コード，図表および主張を著者が原資料と照合します．DICOM，NIfTI，患者情報，症例対応表，個人情報，非公開URL，認証情報および未公開研究データは，承認されていない外部サービスへ入力しません．

確認先として，[中部大学「生成AI利用ガイドライン（第2報）」](https://www.chubu.ac.jp/news/24270/)と[IEEEのAI生成テキストに関する著者向け指針](https://open.ieee.org/author-guidelines-for-artificial-intelligence-ai-generated-text/)を案内します．`examples/ai-usage-example.tex`は，[宇佐美らの論文](https://arxiv.org/abs/2606.15610)にあるAI利用申告を，利用範囲と人間の検証責任を分ける参考例として引用しています．この論文を研究内容の先行研究として引用するかは別の判断であり，実際に論旨と関係するときだけ原論文を読んで引用してください．

## 記入例と執筆ガイド

各章ファイルには，何を書くか，何を区別するか，対応する内容入り例をコメントで記載しています．章全体の書き方は`WRITING_GUIDE.md`，提出前の完了条件は`CHECKLIST.md`で確認してください．内容入りの例は`examples/`へ隔離し，可視注記を「［架空の記入例・提出不可］」へ統一しています．通常の原稿には読み込まれません．対応関係と安全な使い方は`examples/README.md`にあります．

## ローカルでのビルド

TeX Live 2025以降を想定しています．macOSではフル構成のMacTeXまたはTeX Liveを推奨します．LuaLaTeX，Biber，latexmkおよびIPAexフォントを利用できることを確認します．

```bash
lualatex --version
biber --version
latexmk -v
```

ルートで次を実行すると，`latexmk`がLuaLaTeXとBiberを必要な回数だけ実行します．

```bash
latexmk main.tex
latexmk abstract.tex
```

引用や相互参照が更新されない場合は，`latexmk -C`で生成物を削除してから再実行します．`latexmk -C`はTeXソースを削除しません．

### Overleafで大容量・長時間ビルドになる場合

高解像度画像や多数の図によってアップロードまたはコンパイルが重くなった場合は，Source ZIPを取得し，ローカルでビルドしてください．DICOM，NIfTI，動画，生データ，モデル重み，checkpointおよび実験出力一式はLaTeXの入力ではないため，Overleafへ置きません．承認された研究用ストレージで管理し，論文には掲載に必要な最終図だけを`figures/`へ出力します．

折れ線図，模式図および文字を含む図は可能ならPDF，写真や画像例は用途に応じてPNGまたはJPEGを使います．巨大な元画像を`\includegraphics`の表示倍率だけで縮小せず，掲載寸法に見合う解像度の派生画像を書き出してください．

Overleafへ戻すときは，更新した`.tex`，`.bib`，クラス・スタイルファイルおよび掲載用図だけを同期します．`.aux`，`.bbl`，`.bcf`，`.blg`，`.fdb_latexmk`，`.fls`，`.log`，`.out`，`.run.xml`，`.toc`，`main.pdf`および`abstract.pdf`は再生成物なのでアップロードしません．ローカルとOverleafの結果を比較する場合は，CompilerとTeX Liveの世代を揃えます．

## Overleafでの運用

- 卒業論文と修士論文は別プロジェクトとしてアップロードする．
- Compilerは`LuaLaTeX`，TeX Liveは`2025`とし，独自にpdfLaTeXやXeLaTeXへ変更しない．
- Main documentは`Settings`（左下の歯車）→ `Compiler`で切り替える．本文を作るときは`main.tex`，独立アブストラクトを作るときは`abstract.tex`を選ぶ．
- 引用，目次または相互参照が更新されないときは`Recompile from scratch`を実行する．
- 本文PDFとアブストラクトPDFは，ダウンロード直後に識別できる別名へ変更し，それぞれのページ構成をPDFビューアで確認する．

Main documentの設定は，Overleaf公式の[The Main document](https://docs.overleaf.com/getting-started/recompiling-your-project/the-main-document)も参照してください．

## コンパイルで困った場合

- 未記入の初期状態では，metadata未設定と`Empty bibliography`の警告が出る．入力後の最終稿では，metadataを埋め，引用がある場合は参考文献一覧が生成されて警告が解消したことを確認する．
- 本版は`luatexja-preset`の`ipaex`設定を使う．IPAexフォントが見つからない場合は，TeX Liveの不足パッケージを追加するか，フル構成のMacTeX／TeX Liveへ切り替える．クラスファイルを別フォントへ書き換えて回避しない．
- 引用が`[?]`，相互参照が`??`のままなら，引用キーと`references.bib`，`\label`と`\ref`の綴りを確認し，`Recompile from scratch`を実行する．
- `Overfull \hbox`または`Overfull \vbox`が出た場合は，長いURL，数式，表，図または文章を調整し，PDFの見切れも目視する．
- ページ数エラー後にもPDFが表示される場合があるため，ログだけでなく物理ページ数を確認する．
- Main documentを誤って選んだ場合は，本文なら`main.tex`，独立アブストラクトなら`abstract.tex`へ戻して再コンパイルする．

## 提出前

`CHECKLIST.md`を上から確認してください．とくに，大学院の所属の正式名称，題目の一致，架空例の残存，研究業績，各PDFの参考文献一覧と独立した採番，匿名化，生成AI等の利用申告およびアブストラクト2頁を確認します．

## テンプレートへの謝意と由来

本テンプレートを再構成するにあたり，卒業論文テンプレートをご提供いただいた奥居先生に感謝申し上げます．

提供された旧テンプレート内部には，石原進先生作成のクラスファイルを基にした旨の記載がありました．先行する組版整備に敬意を表します．この来歴は旧ファイル内の記載に基づくものであり，原資料，改変履歴および権利関係を独立に確認したものではありません．両先生の氏名の記載は，本テンプレートの監修，承認または内容保証を意味しません．

本テンプレートのLaTeXコードは，宇佐美研究室がLuaLaTeX向けに新たに再構成したものです．旧テンプレートに含まれていたクラスファイル，スタイルファイル，フォント設定ファイル等は，同梱・再配布していません．詳細は`NOTICE.md`を参照してください．
