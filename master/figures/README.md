# 図ファイル

論文で使う図をこのフォルダへ置きます．LuaLaTeXではPDF，PNG，JPEG形式を推奨します．

- グラフや模式図は，可能ならPDFで書き出す．
- 写真やスクリーンショットは，PNGまたはJPEGを用いる．
- ファイル名は半角英数字とハイフンを基本とし，空白を避ける．
- 図を作成した元データと生成手順も，修了後に再現できる形で保管する．
- 他者が作成した図を転載・改変する場合は，出典と利用条件を確認する．

挿入例は`WRITING_GUIDE.md`を参照してください．このREADMEは，空の`figures/`フォルダをOverleafへ確実に含めるためにも置いています．
